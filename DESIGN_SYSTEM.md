# Fosko Design System

## Brand character
Fosko should feel:
- Minimal
- Quiet
- Precise
- Open
- Thoughtful
- Contemporary

Avoid visual noise, excessive decoration, dense layouts, and trend-driven effects.

## Brand message
Primary: `Make possibility tangible.`
Japanese: `可能性を、かたちにする。`

## Color palette
- Navy: `#172a3a`
- Lagoon: `#91aabe`
- Fog: `#f4f3ef`
- Paper: `#fbfaf7`
- Ink: `#141719`
- Muted text: `#667078`

Do not change brand colors without an explicit design decision.

## Typography
- English display text: Montserrat
- Japanese body text: Noto Sans JP

Principles:
- Prefer restrained font weights.
- Preserve generous whitespace.
- Maintain strong hierarchy without heavy visual weight.
- Avoid unnecessary bolding.
- Heading semantics must not change visual appearance unintentionally.

## Layout
- Wide, calm desktop composition.
- Clear single-column behavior on mobile.
- Responsive breakpoint currently centers around `720px`.
- Important content must never overlap or collapse at mobile widths.
- Fixed header behavior must not obscure anchor destinations.

## Geometry
Use thin rules, restrained circles/arcs, soft gradients, and large negative space.
Avoid heavy shadows, dense card grids, decorative icon overload, and unnecessary motion.

## Accessibility
- Preserve visible keyboard focus.
- Maintain readable color contrast.
- Decorative images should use `alt=""`.
- Meaningful images require useful alternative text.
- Respect `prefers-reduced-motion`.
- Preserve semantic heading order where practical.

## Design review output
1. Problem
2. Intended visual outcome
3. Exact elements affected
4. Constraints
5. Minimal implementation guidance

Do not provide unrelated redesign ideas unless explicitly requested.
